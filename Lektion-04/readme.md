# Lektion 4

## Westcoast Cars

Westcoast Cars är en fiktiv bilhandel som säljer begagnade biler på västkusten.

### Kommma igång

För att komma igång måste kommandot `npm i` köras ifrån katalogen _westcoast-cars_
Öppna upp terminalen i vscode och köra följande kommando `npm run server` detta startar upp en inline _json-server (REST API)_.

Öppna upp en webbläsare och skriv in följande adress i adressfältet: http://localhost:3000/vehicles. Vad ni kommer att se är ett json resultat med aktuella bilar i databasen.

Högerklicka på filen _index.html_ och välj öppna med (Open with) _Live Server_. (Live Server är ett tillägg till VSCode av Ritwick Dey).
